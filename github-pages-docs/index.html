GitHub Pages Docs — Demo Index

Five ways to host documentation on GitHub Pages, each demoing the same sample content. Served from https://frankyz-dev.github.io/github-pages-docs/ — the local mock server (server/server.mjs) mirrors this exact layout.

  • Astro + Starlight /github-pages-docs/astro/

    Docs theme on the Astro static site generator. Pagefind search, MDX, mermaid.

  • Docusaurus /github-pages-docs/docusaurus/

    React-based docs framework (Meta). Local search, versioning, mermaid theme.

  • MkDocs Material /github-pages-docs/mkdocs/

    Python-based MkDocs with the Material theme. Search, mermaid via CDN.

  • VitePress /github-pages-docs/vitepress/

    Vue-based, Vite-powered docs engine. Local search, mermaid plugin.

  • Plain Markdown /github-pages-docs/plain-md/

    No generator — the raw Markdown files, rendered the way GitHub's built-in renderer would.

All five demos render the same sample content (design doc, SOPs, runbooks for the fictional Acme Order Service). See DEMO_NOTES.md for observations and README.md for setup.
