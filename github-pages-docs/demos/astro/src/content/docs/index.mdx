This site is the **Astro Starlight** demo (Option 6) in the docs-framework
comparison. It serves the shared sample content with:

- **Pagefind** full-text search (built into Starlight, indexed at build time)
- **MDX** with an interactive React island (order-state stepper) in the
  architecture doc
- **Content collections** with typed frontmatter (`lastUpdated` on SOPs,
  `severity` on the runbook)
- **Mermaid** diagrams rendered client-side
- **Dark mode** on by default
