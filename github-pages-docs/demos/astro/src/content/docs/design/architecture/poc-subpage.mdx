title: 'POC Subpage'
---

This is an intentionally near-empty page. It exists to prove how Astro
Starlight nests subpages in the sidebar: a directory with an `index.mdx`
(`design/architecture/`) becomes a collapsible **group** in the autogenerated
sidebar, with the index page as its first link and sibling pages (like this
one) nested beneath it. Note that Starlight does *not* support nesting items
under a link item (`{ label, link, items }` is rejected by its sidebar
schema), so the parent entry is a group named after the directory, not the
Architecture page itself.
